`check_cpu.py` is the CPU build/validation entry for Zarael sandbox. It compiles Python to `/out`, seals inputs, runs synthetic control/protocol tests, prints dry-run and engine-build recipes, and retains a validation record. No actual model, server or GPU is used. `freeze.json` is generated by that check and its SHA-256 is embedded in `queue-step.txt` after validation. A SHA is an integrity check, not authority to launch.
